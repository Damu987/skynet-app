# Skynet Eats 

Skynet Eats is a **modern, responsive grocery and food delivery landing page** built using **HTML5 and CSS3**.  
The concept is based on a futuristic **drone-powered delivery service** that brings groceries straight to your window.

This project focuses on **semantic HTML, accessibility, layout design, and clean UI structure**.

---

## Features

- Responsive navigation bar
- Skip-to-content accessibility link
- Hero section with call-to-action
- Informational statistics section
- About section with branding
- Email notification signup form
- Footer with social media links
- Modern fonts and icons
- Clean and structured layout

---

## Technologies Used

- HTML5 (Semantic HTML)
- CSS3
- Google Fonts (Poppins)
- Normalize.css
- Iconify Icons
- Ionicons
